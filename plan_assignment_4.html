Overview

Design an Extended Kalman filter that estimates the robot's pose \((x, y, \varphi)\) in a world frame, using the wheel speeds to predict and the front + side IR distances to two walls to correct. Simulate it on logged data, then run it on the robot.

$$\bar{\mathbf x}_k = f(\mathbf x_{k-1}, \mathbf u_k),\quad \bar{\mathbf P}_k = \mathbf F_k\mathbf P_{k-1}\mathbf F_k^\mathsf T + \mathbf B_k\mathbf G\mathbf B_k^\mathsf T \qquad \mathbf y_k = \mathbf z_k - h(\bar{\mathbf x}_k),\quad \mathbf K = \bar{\mathbf P}_k\mathbf H_k^\mathsf T(\mathbf H_k\bar{\mathbf P}_k\mathbf H_k^\mathsf T + \mathbf R)^{-1}$$

The three parts of the assignment (same as A3, now nonlinear):

  1. Specify the matrices: Jacobians \(\mathbf F_k, \mathbf B_k\) of the motion model, its uncertainty \(\mathbf Q_k = \mathbf B_k\mathbf G\mathbf B_k^\mathsf T\), and \(\mathbf H_k, \mathbf R\) of the measurement model.
  2. Simulate the EKF in Python on logged inputs and measurements.
  3. Run the EKF on the robot by filling in state_estimator.cpp.

Deliverable: the Arduino script + the relevant Jupyter notebook(s), uploaded to Toledo at least 24 h before the defense, then a defense. Every code block must be understood by both of us, so blocks are short and start with a one-line comment on what it does and what to tweak.

2.1 The model

State \(\mathbf x = [x, y, \varphi]^\mathsf T\) (m, m, rad), input \(\mathbf u = [\omega_A, \omega_B]^\mathsf T\) (wheel speeds, rad/s), as in the template:

$$v = \frac{r(\omega_A + \omega_B)}{2},\qquad \omega = \frac{r(\omega_B - \omega_A)}{W}$$ $$f(\mathbf x, \mathbf u) = \begin{bmatrix} x + \Delta t\, v\cos\varphi \\ y + \Delta t\, v\sin\varphi \\ \varphi + \Delta t\,\omega \end{bmatrix}$$ $$\mathbf F_k = \begin{bmatrix} 1 & 0 & -\Delta t\, v\sin\varphi \\ 0 & 1 & \Delta t\, v\cos\varphi \\ 0 & 0 & 1 \end{bmatrix},\qquad \mathbf B_k = \begin{bmatrix} \tfrac{r\Delta t}{2}\cos\varphi & \tfrac{r\Delta t}{2}\cos\varphi \\ \tfrac{r\Delta t}{2}\sin\varphi & \tfrac{r\Delta t}{2}\sin\varphi \\ -\tfrac{r\Delta t}{W} & \tfrac{r\Delta t}{W} \end{bmatrix}$$ $$\mathbf G = \begin{bmatrix}\sigma_{\omega}^2 & 0 \\ 0 & \sigma_{\omega}^2\end{bmatrix}\quad[(\text{rad/s})^2],\qquad \mathbf Q_k = \mathbf B_k\mathbf G\mathbf B_k^\mathsf T$$

Evaluate at the estimate before the update (\(\varphi = \hat\varphi_{k-1}\)). Ch 6.2 uses the same idea with input (distance, heading change) \(= (v\Delta t, \omega\Delta t)\). In the template, G is called Q (2×2) and _Phat = A*_Phat*~A + B*Q*~B.

2.2 SymPy check (goes into the notebook)

Jacobians of the motion model Python
# Motion model and its Jacobians with SymPy (as Ch 6.2.1.3). Prints F_k and B_k.
# TWEAK: nothing; change f if you change the model (e.g. heading phi + omega*dt/2).
import sympy as sp
x, y, phi, wA, wB, dt, r, W = sp.symbols('x y phi omega_A omega_B Delta_t r W')
v  = r*(wA + wB)/2                     # forward speed
om = r*(wB - wA)/W                     # turn rate (B faster -> turn left)
f = sp.Matrix([x + dt*v*sp.cos(phi),
               y + dt*v*sp.sin(phi),
               phi + dt*om])
F = f.jacobian([x, y, phi]); B = f.jacobian([wA, wB])
display(sp.simplify(F), sp.simplify(B))

The template's \(\omega = r(\omega_B - \omega_A)/W\) means: B faster ⇒ \(\omega > 0\) ⇒ turning left (counter-clockwise, \(\varphi\) grows). That's only true if B is the right wheel. Check with the A2 rotate-in-place log (E4): when GyroZ is positive (CCW, if Z points up), should \(\omega_B - \omega_A\) be positive. If not, swap the sign in the model.

3.1 Distance along a ray to a wall

A sensor at position \(\mathbf p\) looking in direction \(\psi\) hits the wall \(a x + b y = c\) after a distance

$$d = \frac{c - a p_x - b p_y}{a\cos\psi + b\sin\psi}$$

(the perpendicular distance divided by the cosine of the angle of incidence). With frame A (walls \(x = 0\), \(y = 0\)), the front sensor at \(\alpha\) in front of the axle looking along \(\varphi\), and the side sensor at \(\beta\) in front and \(\gamma\) to the left, looking along \(\varphi + 90°\):

$$h(\mathbf x) = \begin{bmatrix} \dfrac{c_1 - x}{\cos\varphi} - \alpha \\[2mm] \dfrac{c_2 - y}{\cos\varphi} - \beta\tan\varphi - \gamma \end{bmatrix}\qquad (c_1 = c_2 = 0\ \text{in frame A})$$ $$\mathbf H_k = \begin{bmatrix} -\dfrac{1}{\cos\varphi} & 0 & \dfrac{(c_1 - x)\sin\varphi}{\cos^2\varphi} \\[2mm] 0 & -\dfrac{1}{\cos\varphi} & \dfrac{(c_2 - y)\sin\varphi - \beta}{\cos^2\varphi} \end{bmatrix}$$

Check at the template start \((-0.3, -0.2, 0)\): front reads \(0.3 - 0.085 = 0.215\) m, side \(0.2 - 0.073 = 0.127\) m. Both inside the sensor range. ✓

What H says about the heading: at \(\varphi = 0\) the front sensor's \(\partial h/\partial\varphi = 0\): a small rotation doesn't change its reading. The side sensor still has \(-\beta\): because it sits β in front of the axle, rotating moves it towards/away from the side wall. So the heading is corrected mainly through the side sensor. Mention this in the report (observability). own derivation

3.2 SymPy check

h and H for a sensor ray to a wall Python
# Measurement model: distance along a sensor ray to the wall a*x + b*y = c, and its Jacobian.
# TWEAK: sensor that looks RIGHT -> psi0 = -pi/2 and s = -gamma.
a, b, c, l, s, psi0 = sp.symbols('a b c l s psi_0')
al, be, ga = sp.symbols('alpha beta gamma')
def ray_to_wall(a, b, c, l, s, psi0):
    px = x + l*sp.cos(phi) - s*sp.sin(phi)              # sensor position: l ahead, s to the left
    py = y + l*sp.sin(phi) + s*sp.cos(phi)
    psi = phi + psi0                                    # direction of the ray
    return (c - a*px - b*py) / (a*sp.cos(psi) + b*sp.sin(psi))
c1, c2 = sp.symbols('c_1 c_2')
h = sp.Matrix([ray_to_wall(1, 0, c1, al, 0, 0),         # front sensor -> wall x = c1
               ray_to_wall(0, 1, c2, be, ga, sp.pi/2)]) # side sensor (left) -> wall y = c2
H = h.jacobian([x, y, phi])
display(sp.simplify(h), sp.simplify(H))

5.1 Values

$$\mathbf R = \begin{bmatrix}\sigma_{front}^2 & 0\\ 0 & \sigma_{side}^2\end{bmatrix}\ [\text{m}^2],\qquad \mathbf G = \begin{bmatrix}\sigma_\omega^2 & 0\\ 0 & \sigma_\omega^2\end{bmatrix}\ [(\text{rad/s})^2]$$
  • Off-diagonals 0: the two IR sensors and the two encoders have independent noise (Ch 6.2.2 makes the same assumption).
  • Example: σω = 0.35 rad/s (one encoder count per sample) → G = 0.12 (rad/s)² on the diagonal.
  • Speed noise alone ignores wheel slip and an imperfect wheel radius/wheelbase, which matter more in turns. If G1 shows a larger heading error than P predicts, increase G (Ch 6 uses a variance that grows with the input: std_dist*u[0]**2).

6.1 The EKF functions

predict / correct, same equations as state_estimator.cpp Python
# EKF for the corner set-up (frame A: walls x = 0 and y = 0). Same equations as the robot.
# TWEAK: geometry (Step 1), G and R (Step 5).
import numpy as np
r, W, dt = 0.0325, 0.166, 0.01
al, be, ga = 0.085, 0.09, 0.073                     # sensor offsets (m), measure ours
G = np.diag([0.12, 0.12])                           # wheel-speed noise (rad/s)^2

def predict(X, P, wA, wB):
    # nonlinear motion f + covariance with Jacobians F, B (Step 2)
    x, y, ph = X
    v, om = r*(wA + wB)/2, r*(wB - wA)/W
    F = np.array([[1, 0, -dt*v*np.sin(ph)],
                  [0, 1,  dt*v*np.cos(ph)],
                  [0, 0,  1]])
    B = np.array([[dt*r/2*np.cos(ph), dt*r/2*np.cos(ph)],
                  [dt*r/2*np.sin(ph), dt*r/2*np.sin(ph)],
                  [-dt*r/W,           dt*r/W]])
    X = np.array([x + dt*v*np.cos(ph), y + dt*v*np.sin(ph), ph + dt*om])
    return X, F @ P @ F.T + B @ G @ B.T

def correct(X, P, z, R, c1=0.0, c2=0.0):
    # predicted readings h(x) and Jacobian H (Step 3), then the standard update
    x, y, ph = X
    cp, sp_ = np.cos(ph), np.sin(ph)
    h = np.array([(c1 - x)/cp - al,
                  (c2 - y)/cp - be*sp_/cp - ga])
    H = np.array([[-1/cp, 0,     (c1 - x)*sp_/cp**2],
                  [0,     -1/cp, ((c2 - y)*sp_ - be)/cp**2]])
    nu = z - h
    S = H @ P @ H.T + R
    K = P @ H.T @ np.linalg.inv(S)
    return X + K @ nu, (np.eye(3) - K @ H) @ P, nu, S

7.1 state_estimator.cpp

PredictionUpdate C++
#include "state_estimator.h"

// PREDICTION: unicycle model, input = wheel speeds (u(0) = A, u(1) = B), rad/s.
// TWEAK: Q = wheel-speed noise variances (rad/s)^2  (= G in the notebook).
void PredictionUpdate(const BLA::Matrix<2> &u, BLA::Matrix<3> &xhat, BLA::Matrix<3,3> &_Phat) {
  const float dt = TSAMPLE;
  float x = xhat(0);
  float y = xhat(1);
  float phi = xhat(2);
  float v = (u(0) + u(1))*R_WHEEL / 2;             // forward speed, m/s
  float omega = (u(1) - u(0))*R_WHEEL / WHEELBASE;  // turn rate, rad/s (B faster -> left)

  // Jacobians at the current estimate (Step 2)
  BLA::Matrix<3,3> A = {1, 0, -dt*v*sin(phi),
                        0, 1,  dt*v*cos(phi),
                        0, 0,  1};
  BLA::Matrix<3,2> B = {dt*R_WHEEL/2*cos(phi), dt*R_WHEEL/2*cos(phi),
                        dt*R_WHEEL/2*sin(phi), dt*R_WHEEL/2*sin(phi),
                        -dt*R_WHEEL/WHEELBASE, dt*R_WHEEL/WHEELBASE};
  BLA::Matrix<2,2> Q = {0.12, 0,
                        0,    0.12};             // (rad/s)^2  <- Step 5

  // Nonlinear prediction f(x, u), not A*x + B*u (Ch 6.1)
  xhat(0) = x + dt*v*cos(phi);
  xhat(1) = y + dt*v*sin(phi);
  xhat(2) = phi + dt*omega;

  _Phat = A*_Phat*~A + B*Q*~B;
}
CorrectionUpdate C++
// CORRECTION: front sensor -> wall x = c1, side sensor (looking left) -> wall y = c2.
// TWEAK: alpha, beta, gamma (Step 1), R (Step 5).
void CorrectionUpdate(const BLA::Matrix<2> &z, float weq1[3], float weq2[3], BLA::Matrix<3> &xhat, BLA::Matrix<3,3> &Phat, BLA::Matrix<2> &nu, BLA::Matrix<2,2> &S) {
  const float alpha = 0.085;  // front sensor: m in front of the axle   <- measure
  const float beta  = 0.09;   // side sensor:  m in front of the axle   <- measure
  const float gamma = 0.073;  // side sensor:  m left of the axle middle <- measure

  BLA::Matrix<2,2> R = {1.3e-5, 0,
                        0,      1.3e-5};          // m^2  <- Step 5

  float x = xhat(0), y = xhat(1), phi = xhat(2);
  float c1 = weq1[2];                              // front wall: x = c1
  float c2 = weq2[2];                              // side wall:  y = c2
  float cp = cos(phi), sp = sin(phi);

  // predicted readings h(x) and Jacobian H (Step 3)
  BLA::Matrix<2> h = {(c1 - x)/cp - alpha,
                      (c2 - y)/cp - beta*sp/cp - gamma};
  BLA::Matrix<2,3> H = {-1/cp, 0,     (c1 - x)*sp/(cp*cp),
                        0,     -1/cp, ((c2 - y)*sp - beta)/(cp*cp)};

  nu = z - h;                                      // innovation, m
  S = H*Phat*~H + R;
  BLA::Matrix<3,2> K = Phat*~H*Inverse(S);         // Kalman gain
  xhat += K*nu;
  Phat -= K*H*Phat;
}
